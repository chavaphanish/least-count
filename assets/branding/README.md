# YAYDU artwork

`yaydu-original.png` is the supplied `Yaydu.png`, unchanged. The source is 292×340, with a thin external image frame. `scripts/generate-branding.py` removes that frame, maps the monochrome symbol to existing theme gold (`#e9cd91`), and pads to a square without stretching, rotating or redrawing it. The grayscale mask clamps only near-black/near-white tonal variation (`-level 5%,95%`) and preserves the source anti-aliasing before Lanczos enlargement. No binary threshold or geometric redraw is used. This fixes the staircase edges caused by the earlier low-resolution threshold. The original bitmap limits recoverable detail; no original vector has been supplied. Install icons have solid `#0c2e26` backgrounds, sharp square canvases, no text and mask-safe padding. Android launchers may apply their own platform mask.

Run `python scripts/generate-branding.py` with ImageMagick 7 installed to regenerate web/native artwork. This tool is not required for normal development or deployment.

The original Chavium Games raster logo is restored unchanged from the approved gold artwork. Its font is baked into the image and cannot be identified from metadata; the user approved the existing DM Sans 700 for prominent YAYDU text. `DualBrand` shares the symbol, wordmark and studio fill across startup and navigation; the orientation guard uses its static mode. Major route/Lounge view transitions use a roughly 1.1-second presentation cover with a 1.5-second cleanup limit. Controllers remain mounted, and online game activation suppresses the cover immediately. No background requests, turns or card actions initiate branding transitions.
