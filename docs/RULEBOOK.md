# Rulebook reference

The original uploaded [Edition 2.0 working draft](../RULEBOOK.md) remains at the repository root, unchanged. Read it together with the [confirmed rule decisions](rule-clarifications.md), which override conflicts in that draft.

Room hosts can now choose a positive elimination threshold (default 100) and timed (60 seconds) or untimed play. These are the two intentional room-specific overrides authorized for the multiplayer feature. No other gameplay rules are changed by the lobby.
